# 🏭 스마트 산업현장 에너지·안전 통합 관리 시스템

산업 현장의 에너지 사용량과 안전 데이터를 통합적으로 **수집 · 분석 · 시각화**하여  
**사고 예방** 및 **에너지 절감**을 실현하는 통합 대시보드 기반 시스템

---

## 📌 프로젝트 개요

산업 현장에서 에너지 소비를 최적화하고 작업자 안전을 사전에 예방하는 AI 기반 통합 관리 시스템입니다. 실시간 센서 데이터를 활용하여 위험 상황과 비효율적 에너지 사용을 예측하고, 직관적인 대시보드로 시각화하여 즉각적인 대응이 가능하도록 설계되었습니다.

### 🎯 목적
- 전력, 온도, 가스, 진동 등의 **센서 기반 실시간 시뮬레이션**
- **기준 초과 시 실시간 경고 및 대응**
- **에너지 소비 최적화** 및 **산업 사고 예방**
- **실시간 시각화 및 자동 보고서 생성**
- **현장 적용 가능한 통합 시스템 구축**

### 📊 선정 배경
- 산업현장 사고의 지속적 발생으로 사전 예측 시스템 필요성 대두
- 에너지 가격 상승과 효율성 요구 증가
- 스마트팩토리 환경의 확산으로 자동화 및 데이터 기반 관리 수요 증가
- AI 기술을 활용한 다양한 센서 데이터 해석 및 예측 능력 확대

### ✅ 기대효과
- 📉 **에너지 낭비 감축** 및 **비용 절감**
- 🛡 **산업 재해 위험** 사전 탐지 및 예방
- 📊 **데이터 기반 운영**으로 신뢰성 확보
- 🔁 **시각화 + 이력 관리** 기능을 통한 공정 최적화

### 개발 환경
- **언어**: Python, C++ (센서 시뮬레이터)
- **시각화**: `PyQt5`, `matplotlib`, `Streamlit`
- **데이터 처리**: `pandas`, `numpy`
- **데이터베이스**: `MySQL`
- **PDF 출력**: `ReportLab`
- **AI/ML**: `scikit-learn`, `XGBoost`, `Isolation Forest`

### 데이터 흐름
1. C++에서 센서 데이터 시뮬레이션 후 sensor_result.csv 저장
2. Python에서 해당 파일을 읽어 AI 예측 수행
3. 예측 결과는 csv파일과 MySQL에 저장
4. Streamlit과 PyQt5에서 MySQL을 실시간 조회하여 시각화

## 🤖 AI 예측 모델

### AI 모델 구성

| 모델 | 목적 | 알고리즘 | 결과 |
| --- | --- | --- | --- |
| 위험 예측 | 사고 가능성 판단 | Logistic Regression | 정상 / 위험 |
| 고장 예측 | 기계 진동 분석 | Decision Tree | 정상 / 고장 |
| 위험 등급 | 위험도 등급화 | Random Forest | GREEN~RED |
| 이상치 탐지 | 비정상 탐지 | Isolation Forest | 정상 / 이상 |
| 에너지 과소비 | 과소비 감지 | Threshold / XGBoost | 정상 / 경고 |

### 위험 예측 vs 이상치 탐지

| 구분 | 위험 예측 | 이상치 탐지 |
| --- | --- | --- |
| 방식 | 사전 정의 기준 기반 | 패턴 이상 감지 |
| 목적 | 실제 위험 판단 | 이상 상황 감지 |
| 기술 | AI 이진 분류 or 등급 분류 | Isolation Forest |
| 저장 테이블 | event_log | anomaly_log |

## 📊 대시보드 GUI

### 주요 대시보드 기능

| 기능 | 설명 |
| --- | --- |
| 센서 데이터 시뮬레이션 | 온도, 습도, CO2, 진동 데이터를 주기적으로 갱신하여 실시간 수집 흐름 시뮬레이션 |
| 실시간 대시보드 | PyQt5 기반 GUI로 실시간 센서 테이블, 그래프, 카드 상태, 예측 탭을 시각화 |
| 임계값 감지 및 경고 카드 | 센서 값이 사전에 설정된 임계값을 초과하면 경고색 및 아이콘으로 시각 피드백 |
| 예측 결과 시각화 | 이상치, 고장, 위험도 예측 결과를 테이블 + 그래프로 시각화 |
| 예측 통계 요약 | 위험 예측 분포를 파이 차트 및 통계 테이블로 요약 |

| 외부 파이썬 스크립트 실행 | 버튼 클릭 시 main predictor 스크립트 실행 → 결과를 GUI에 반영 |

### Streamlit 대시보드

대시보드는 다음 탭으로 구성되어 있습니다:
- 메인 탭: 전체 시스템 상태 요약
- 위험 이벤트: 위험 예측 결과 및 이력
- 고장 로그: 기계 고장 예측 및 이력
- 복합 위험도: 위험 등급 분류 결과
- 이상치 탐지: 이상 패턴 감지 결과
- 에너지 과소비: 에너지 낭비 탐지 결과
- 센서 이상: 센서 오작동 탐지 결과

## 🚨 위험 등급 분류 기준

### 센서별 위험 기준
- **온도**
  - 🟢 Green: 20°C ~ 50°C
  - 🟡 Yellow: 51°C ~ 65°C
  - 🔴 Red: ≥ 66°C
- **습도**
  - 🟢 Green: 30% ~ 60%
  - 🟡 Yellow: 20% ~ 29% 또는 61% ~ 70%
  - 🔴 Red: < 20% 또는 > 70%
- **진동**
  - 🟢 Green: ≤ 4.5 mm/s
  - 🟡 Yellow: 4.6 ~ 7.1 mm/s
  - 🔴 Red: > 7.1 mm/s
- **CO₂**
  - 🟢 Green: ≤ 1000 ppm
  - 🟡 Yellow: 1001 ~ 2000 ppm
  - 🔴 Red: > 2000 ppm

## ♻️ 에너지 효율 정상화를 위한 전략

### ✅ 스마트 제어 방식
| 항목 | 과소비 상황 예시 | 정상화 조치 |
|------|------------------|--------------|
| 전등/조명 | 점심시간, 불필요한 공간 조명 ON | 자동 소등 or 인체감지 기반 제어 |
| 전동기/기계 | 유휴 상태에서도 계속 작동 중 | 자동 슬립모드 전환, 전력 차단 |
| 에어컨 | 창문 열려있는 상태에서 작동 | 알림 → 자동 OFF or 환기 유도 |
| 히터 | 외기 온도와 무관하게 고출력 가동 | 온도센서 기반 히터 출력을 자동 조절 |

### ✅ 사용자 경고 및 행동 유도
- "문이 열린 상태에서 에어컨 작동 중" → 팝업 알림
- 실시간 대시보드에서 빨간 경고 아이콘 표시
- 사용자에게 에너지 사용 리포트 제공

### ✅ 자동 스케줄 기반 최적화
- 야간 시간엔 자동 절전 모드 진입
- 전력 피크 시간대에 일부 장비 자동 대기 전환

### ✅ AI 기반 패턴 분석 (향후 고도화)
- 머신러닝으로 과거 패턴 학습 → 이상 사용 탐지
- "월별 평균보다 30% 이상 증가" 시 경고 및 절전 제안

## 🔍 프로젝트 고찰 및 트러블슈팅

### 주요 트러블슈팅

1. **MySQL 연결 끊김 현상**
   - 문제: 자동 새로고침 시 MySQL 서버와 연결이 끊기는 오류 발생
   - 원인: Streamlit이 실행되고 있으면 새로운 연결을 반복해서 생성 → 연결 과부하
   - 해결: 일정 주기마다 새로고침하도록 수정하여 안정성 확보

2. **이상치 탐지 모델의 과민 반응**
   - 문제: Isolation Forest 모델이 정상인 값도 이상치로 간주하는 현상 발생
   - 해결: contamination 파라미터 조정(0.1 → 0.05)

3. **위험 알림 팝업 과다 발생**
   - 문제: 시뮬레이션 초기 데이터에서 위험 상태가 연속적으로 감지되어 경고창이 과도하게 표시
   - 해결: 위험 알림을 최초 1회만 자동으로 표시하고, 이후에는 사용자가 수동으로 확인할 수 있는 버튼 추가

### 배포 관련 고찰

- Streamlit Cloud와 AWS RDS를 활용한 실시간 대시보드 배포 시도 중 환경 변수 설정 및
  AWS 과금 관련 이슈 경험
- 단순 구현을 넘어 실제 서비스 배포에는 별도의 역량이 요구됨을 체감
