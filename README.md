# 🏭 스마트 산업현장 에너지·안전 통합 관리 시스템

산업 현장의 에너지 사용량과 안전 데이터를 통합적으로 **수집 · 분석 · 시각화**하여  
**사고 예방** 및 **에너지 절감**을 실현하는 통합 대시보드 기반 시스템

---

## 📌 프로젝트 개요

### 🎯 목적

- 전력, 온도, 가스, 진동 등의 **센서 기반 실시간 시뮬레이션**
- **기준 초과 시 실시간 경고 및 대응**
- **에너지 소비 최적화** 및 **산업 사고 예방**

### ✅ 기대효과

- 📉 **에너지 낭비 감축** 및 **비용 절감**
- 🛡 **산업 재해 위험** 사전 탐지 및 예방
- 📊 **데이터 기반 운영**으로 신뢰성 확보
- 🔁 **시각화 + 이력 관리** 기능을 통한 공정 최적화

---

## 🛠 주요 기능

- ⚡ **전력 소비 시뮬레이션 및 공정별 사용량 시각화**
- 🔥 **온도/가스/진동 등 위험요소 감지 및 경고 알림**
- 🧠 **위험 등급 분류 및 실시간 팝업 알림**
- 🗃 **이력 자동 저장 및 조회 기능 (SQLite)**
- 📄 **PDF 리포트 자동 생성 (그래프 + 표 포함)**

### 부가 정보

#### ⚠️ 위험 등급 분류 기준

- **전류**
  - 🟢 Green: ≤ 정격 전류의 80%
  - 🟡 Yellow: 80% ~ 95%
  - 🔴 Red: ≥ 95%

- **온도**
  - 🟢 Green: 20°C ~ 50°C
  - 🟡 Yellow: 51°C ~ 65°C
  - 🔴 Red: ≥ 66°C

- **소음**
  - 🟢 Green: ≤ 75 dB
  - 🟡 Yellow: 76 ~ 85 dB
  - 🔴 Red: ≥ 86 dB

- **조도**
  - 🟢 Green: ≥ 300 lux
  - 🟡 Yellow: 150 ~ 299 lux
  - 🔴 Red: < 150 lux

- **CO₂**
  - 🟢 Green: ≤ 1000 ppm
  - 🟡 Yellow: 1001 ~ 2000 ppm
  - 🔴 Red: > 2000 ppm

#### ♻️ 에너지 효율 정상화를 위한 전략

##### ✅ 스마트 제어 방식

| 항목 | 과소비 상황 예시 | 정상화 조치 |
|------|------------------|--------------|
| 전등/조명 | 점심시간, 불필요한 공간 조명 ON | 자동 소등 or 인체감지 기반 제어 |
| 전동기/기계 | 유휴 상태에서도 계속 작동 중 | 자동 슬립모드 전환, 전력 차단 |
| 에어컨 | 창문 열려있는 상태에서 작동 | 알림 → 자동 OFF or 환기 유도 |
| 히터 | 외기 온도와 무관하게 고출력 가동 | 온도센서 기반 히터 출력을 자동 조절 |

##### ✅ 사용자 경고 및 행동 유도

- "문이 열린 상태에서 에어컨 작동 중" → 팝업 알림
- 실시간 대시보드에서 빨간 경고 아이콘 표시
- 사용자에게 에너지 사용 리포트 제공

##### ✅ 자동 스케줄 기반 최적화

- 야간 시간엔 자동 절전 모드 진입
- 전력 피크 시간대에 일부 장비 자동 대기 전환

##### ✅ AI 기반 패턴 분석 (향후 고도화)

- 머신러닝으로 과거 패턴 학습 → 이상 사용 탐지
- "월별 평균보다 30% 이상 증가" 시 경고 및 절전 제안
